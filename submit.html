Submission Guidelines & Link

How to Submit

Aspiration Publishing Trust currently accepts manuscript submissions via the following routes until ScholarOne/OJS is configured.

Manuscript Submission Portal

Maximum file size allowed: 25MB.

Backup & Alternative Submission

  • Email (backup): eic@aspsonline.com (attach manuscript in DOCX + PDF)
  • Microsoft CMT (alternative): Click the Submit button Submit

Required Files

  • Main manuscript (DOCX)
  • Anonymous PDF (for review)
  • Cover letter (optional)
  • Author ORCID IDs
  • Ethical approval statement (if applicable)

Review Timeline

Initial editorial screening: 3–7 days. Peer review: 2–4 weeks. Final decision typically within 6 weeks.

Note: When ScholarOne is set up you will be notified and the official submission link will replace this page.
